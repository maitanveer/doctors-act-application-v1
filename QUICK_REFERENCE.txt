👤 USER ROLES & PERMISSIONS
═══════════════════════════════════════════════════════════════════════
USER (Default on registration):
  ✅ View website
  ✅ Submit applications
  ❌ No admin access

ADMIN:
  ✅ All user permissions
  ✅ View admin dashboard
  ✅ Manage applications (view, update status, delete, export)
  ✅ Manage users (change roles, activate/deactivate)
  ❌ Cannot create superadmins
  ❌ Cannot modify superadmins

SUPERADMIN:
  ✅ All admin permissions
  ✅ Create/modify other superadmins
  ✅ Full system control
  ✅ Cannot be deactivated by admins

🎯 QUICK ACTIONS
═══════════════════════════════════════════════════════════════════════
Create New Admin:
  1. Login as superadmin
  2. Go to /admin/users
  3. Change user role to "admin"

Review Applications:
  1. Login as admin/superadmin
  2. Go to /admin/applications
  3. Use filters to search
  4. Click "View" to see details
  5. Update status as needed

Bulk Operations:
  1. Go to /admin/applications
  2. Select applications (checkboxes)
  3. Choose bulk action
  4. Click "Apply"

Export Application:
  1. View application details
  2. Click "Export JSON"
  3. File downloads automatically

💻 USEFUL COMMANDS
═══════════════════════════════════════════════════════════════════════
Start Server:
  php artisan serve

Create Another SuperAdmin:
  php artisan tinker
  >>> User::create([
        'name' => 'Admin Name',
        'email' => 'admin2@example.com',
        'password' => Hash::make('password'),
        'role' => 'superadmin',
        'is_active' => true
      ]);

Check All Users:
  php artisan tinker
  >>> User::all();

View Routes:
  php artisan route:list | grep admin

Clear Cache:
  php artisan config:clear
  php artisan cache:clear

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════
Problem: Cannot access admin panel
Solution: 
  - Check if logged in
  - Verify user role in database
  - Run: php artisan config:clear

Problem: 403 Forbidden
Solution:
  - Login with admin/superadmin account
  - Check role middleware is working

Problem: Routes not found
Solution:
  - php artisan route:clear
  - php artisan config:clear
  - Restart server
